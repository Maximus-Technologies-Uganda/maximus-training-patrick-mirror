================================================================================
TROUBLESHOOTING
================================================================================

Problem: Page takes >3 seconds to load
→ Check DevTools Network tab
→ Look at API response time
→ Check if on slow network (3G simulated)
→ SSR should help even on slow networks

Problem: Posts don't appear initially
→ View Page Source (Ctrl+U)
→ Search for first post title
→ Should appear in HTML (not "Loading...")
→ If not in source → SSR issue

Problem: Pagination doesn't work
→ Check DevTools Console for errors
→ Click Next button
→ Look for URL change in address bar
→ Should change from /posts → /posts?page=2

Problem: Can't find design tokens
→ Right-click element → Inspect
→ Look in Styles panel
→ Should see --color-primary, --space-2, etc.
→ Not hardcoded values like #1f2937 or 16px

Problem: Accessibility issues
→ Press Tab key
→ Focus should move to each button
→ Focus ring should be visible
→ Check DevTools → Accessibility tree
