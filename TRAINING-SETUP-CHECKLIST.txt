TITLE PATTERNS FOR YOUR TEAM
═══════════════════════════════════════════════════════════════════════════════

When creating PRs/issues, use these patterns for auto-labeling:

Type Labels (use at start of title):
  feat: new feature          → type:feature
  fix: bug fix               → type:bug
  docs: documentation        → type:docs
  [SPEC] specification       → type:spec
  chore: maintenance         → type:chore
  refactor: code refactor    → type:refactor
  test: test addition        → type:test

Priority Labels (add to title):
  (P0) or critical           → priority:critical
  (P1) or high               → priority:high
  (P2) or medium             → priority:medium
  Otherwise                  → priority:low
