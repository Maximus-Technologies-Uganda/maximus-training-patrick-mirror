INTEGRATION FLOW
================

User navigates to /posts?q=test&author=alice&sort=old
    ↓
SSR page.tsx fetches data and renders with initialData
    ↓
Client hydrates with PostsPageClient
    ↓
User changes filter (e.g., sorts to "old")
    ↓
PostsFilters validates through querySchema
    ↓
PostsFilters calls router.push("/posts?q=test&author=alice&sort=old")
    ↓
URL updates in browser
    ↓
usePosts hook builds canonical key
    ↓
SWR hook fetches data with canonical cache key
    ↓
LiveRegion announces: "Filters applied: query "test", author alice, sorted oldest first"
